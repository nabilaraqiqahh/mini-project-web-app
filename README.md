# Assignment 2 and Mini Project Web App

## DysCover Nexus - 3D Educational Game E-Commerce Platform

This project is a web application designed as an e-commerce platform for "DysCover Nexus," a 3D educational game targeting children with dyscalculia learning challenges.

### Team Members & Tasks

| **Member 2** | Muna | Authentication Developer | Login, register, session, validation |
| **Member 3** | Carine | Product & Database Developer | Product page, database tables, product CRUD |
| **Member 4** | Yuni | Shopping Cart & Checkout Developer | Cart system, checkout page, order flow |

### Project Structure
- `index.html`: Main Landing Page
- `css/style.css`: Global Styles & Theme
- `js/main.js` & `js/validation.js`: Interactivity & Form Validation
- `pages/`: Contains About, Store, Login, Register, Contact, Cart, Checkout, and Confirmation pages.
