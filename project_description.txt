Project 1A: Restaurant Order Management System for Walk-In and Online Customers
Objective:Develop a fully functional order management system that handles orders from both walk-in customers and online customers. The system should ensure smooth and efficient order processing, from order placement to order status updates.
Resources:
 https://drive.google.com/drive/folders/1u6Bk-_hRDnWnTyu1bw6VgqJ2aYcYH3NI?usp=drive_link
Project Requirements:
Walk-In Orders:
QR Code Ordering for Customers: Implement a QR code on each table that customers can scan to view the menu and place their orders directly through the web application.
Waiter-Assisted Ordering: Allow waiters to scan a QR code to place an order for customers, inputting order details into the system on behalf of the customer.
Order Tracking: Once an order is placed, track its status in real-time (e.g., Pending, In Progress, Ready).
Online Orders:
Online Ordering Interface: Create a user-friendly web interface where online customers can browse the menu, add items to the shopping cart, and place an order.
Checkout Process: Implement a checkout process that includes fields for customer name, shipping address (if applicable), and payment information.
Order Confirmation: After placing the order, customers should receive an order confirmation email with details of the order (items, total, and status).
Order Management for Restaurant Staff: Allow restaurant staff to view and update the status of walk-in and online orders. Staff should be able to mark orders as completed and notify the kitchen and waiters for pickup.
Technologies:
Frontend: HTML, CSS, JavaScript.
Backend: PHP and MySQL (or Laravel if preferred).
Implement payment functionality for online orders (e.g. upload payment receipt). 
Collaboration:
Work in a group of 4 students.
Distribute tasks such as front-end development, multimedia integration, content creation, and design among group members.
Project 1B: Order Management System for GRAB or Food Panda Runner Orders
Objective:Create a system for managing orders that are assigned to GRAB or Food Panda runners for delivery. This system will allow restaurant staff to manage delivery assignments, track the status of each delivery, and provide relevant details to the delivery drivers.
Resources:
 https://drive.google.com/drive/folders/1u6Bk-_hRDnWnTyu1bw6VgqJ2aYcYH3NI?usp=drive_link
Project Requirements:
Minimal Functional Requirements:
Member Registration Page (e.g. Membership information) 
Authentication (e.g. Login-password page, session/cookies) 
Member Area (View, Add, Update, Delete)
Form Validation using JavaScript
Formatting display using CSS
Order Assignment to Runners:
Order Assignment Interface: When a customer places an online order or walk-in order that requires delivery, the system should allow restaurant staff to assign the order to a GRAB or Food Panda runner.
Order Details for Delivery: The order details (e.g., customer name, order items, delivery address) should be displayed to the runner through a separate interface.
Tracking Delivery Status:
Delivery Status Updates: Allow GRAB or Food Panda runners to update the status of the delivery in real-time (e.g., Picked up, In Transit, Delivered).
Notifications: Notify restaurant staff when the order has been picked up by the runner and when it is delivered to the customer.
Technologies:
Frontend: HTML, CSS, JavaScript.
Backend: PHP and MySQL (or Laravel if preferred).
Collaboration:
Work in a group of 4 students.
Distribute tasks such as front-end development, multimedia integration, content creation, and design among group members.
